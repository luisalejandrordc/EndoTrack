# EndosoFlow — Phase 1 Requirements Catalog (Employee Side)

## 1. Scope and conventions

This catalog covers Phase 1: the employee application and the core business logic. It builds on the State Machines & Permissions Spec, whose transitions (T1–T5, S1–S7) and permission matrix are referenced here, not repeated. The customer portal (Phase 2) and SLA reminders, BI and exports (Phase 3) get their own catalogs. Phase 1 still stores the data those phases need (for example `eligible_at`, `started_at`, `due_date`).

**Roles:** ADM = System Admin, MGR = Sales Manager, ADV = Sales Advisor (“own” = the sale’s current assigned advisor).

Every authorization rule is enforced on the backend. Every acceptance criterion (AC) that involves a forbidden role must be covered by an automated authorization test.

**Assumption:** in Phase 1, customer records are created with a portal status of “not yet invited”. Activation links (Notification 1) go out when the portal ships in Phase 2.
