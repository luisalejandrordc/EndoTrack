# Decision Log

This log serves as a single source of truth for architectural, design, and strategic decisions made during development.

---

## Active Decisions

- Task definitions and recommended durations live in a reference table.

---

## Log Template

Copy this markdown snippet to create new entries:

```markdown
### [DEC-XXX] Title

- **Status:** Proposed / Approved / Superseded
- **Problem Statement:** What problem are we trying to solve?
- **Outcome:** Selected Option
- **Rationale:** Why was this option chosen?
- **Next Steps:** Action items to execute.
```
